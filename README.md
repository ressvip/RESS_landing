## Quick Start

### 1. Previewing Locally
To run a local live-reload preview server:

```bash
# Serves on http://localhost:3000
npm run dev
```

Or open `index.html` directly in any modern web browser.

### 2. Building Static Pages
To rebuild all pages from `src/pages/`, `src/components/`, and `src/layouts/`:

```bash
npm run build
```

To watch for changes during active template development:

```bash
npm run watch
```

### 3. Downloading Remote Assets
To synchronize remote brand assets from the CDN:

```bash
npm run assets:download
```

## Component Architecture

Templates in `src/pages/` use clean frontmatter and can include reusable components:

```html
---
title: Page Title - RESS
description: Concise description of this page.
showCta: true
---
<section class="my-section">
    <!-- Page-specific content here -->
</section>
```

Reusable components available in `src/components/`:
- `{{> head}}`: Primary meta tags, social graph cards, fonts, and stylesheets.
- `{{> navbar}}`: Top navigation bar with logo, dropdown mega-menu, and CTA.
- `{{> global-cta}}`: Reusable bottom call-to-action banner with store download badges.
- `{{> footer}}`: 5-column footer with live brand config links and legal notices.
- `{{> cookie-banner}}`: Cookie consent banner with accept and decline handling.

## Configuration and Customization

Brand information, contact details, download links, and social links are centrally managed in:

`assets/js/config.js`

### Variables Available:
- **Brand Information**: Site name, legal company title, tagline, logo paths.
- **Contact Details**: Phone numbers, WhatsApp, customer support emails.
- **App Download URLs**: App store links and direct APK downloads.
- **Social Media**: Links for Facebook, Instagram, YouTube, and LinkedIn.

### Dynamic Hydration:
Elements with `data-config` or `data-config-href` attributes are automatically hydrated on page load:
```html
<span data-config="contact.emails.support"></span>
<a data-config-href="contact.phone">Call Us</a>
```

## Design System

Defined in `assets/css/styles.css`:
- **Primary Brand Color**: `#22BDB3` (Tropical Teal)
- **Dark Neutral Background**: `#3A3735` / `#000000`
- **Surface and Cards**: `#FFFFFF` / `#FAFAFA`
- **Typography**: Open Sans (`'Open Sans', -apple-system, BlinkMacSystemFont, sans-serif`)
- **Effects**: Backdrop blurs (`backdrop-filter: blur(12px)`), floating layered cards, and custom responsive breakpoints.
